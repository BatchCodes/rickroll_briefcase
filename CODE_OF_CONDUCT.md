# Code of Conduct

This project uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## Summary

- Be kind and respectful to other people.
- Accept constructive feedback, and give it in a constructive way.
- Do not harass, insult or threaten any person.
- Do not publish the private information of another person.

The full text at the link above applies to all project spaces: issues, pull requests, discussions and any other project channel.

## Reporting

To report unacceptable behaviour, send a private message to a maintainer on GitHub. You can also open a [private security advisory](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) and mark it as a conduct report. The maintainers keep all reports confidential.
